    Image Generation Pipeline:
        We try to understand the intent of the text, possible intents (10 in total) are exactly:
            FUNNY, SAD, ROMANTIC, ANGRY, INFORMATIVE, EXCITED, CELEBRATORY, CALM, MOTIVATIONAL, GRATEFUL

        Each intent is mapped to a list of least 2 font families (2 for English, 2 for Hebrew)
        Each intent is mapped to at least 4 color gradients (common to all languages).
        In addition, we have a predefined list of at least 100 popular diverse emojis, and a dictionary that maps stems to emojis (e.g. "fun" -> 😂, "sad" -> 😢, "romanc" -> ❤️, etc...).
        If we cannot detect the intent of the text we fall back to sentiment analysis (VADER rules).
        Sentiment is mapped to (multiple) intents.
        Emojis are always selected based on the keyword lookup, if no keywords are found we use a default emoji (🫟).

        Pipeline:
            - Detect language + Translate to English (if not already) tokenize and stem (Porter Stemmer).
            - Identify intent based on stems (predefined dictionary of stems to intents).
                - If no intent is found use sentiment analysis to map to an intent.
            - The intent points to a list of fonts (the list of fonts) and to a list of color gradients (the list of gradients).
            - select up to 3 emojis based on the stems.
                - If no emojis are found use the default emoji (🫟).
            - Generate the image (given the intent, and the list of emojis):
                - Image is generated at 512x512 resolution.
                - Select a random font family from the list of fonts
                - Select a random color gradient from the list of gradients
                - Text is on the top and naturally aligned to the start (left for LTR languages, right for RTL languages)
                - emojis at the bottom centered horizontally, with a max of 3 emojis
                - Font size should be set automatically to fill the space of the image, wrap words but do not break them.
                    Use min and max font size guardians to avoid too small or too large fonts.
                    Limit the max text length for image generation, if the text is too long hide the button entirely.
